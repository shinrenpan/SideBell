## ⚠️ 為什麼要用日文測，而不是英文

英文正是 base 語言。**字串漏抽時，畫面上顯示的中文與正確抽出後顯示的英文，
在英文系統下看起來沒有差別**——因為漏抽的字串就是它自己，而抽出的字串
fallback 也是英文。兩種情況都「看起來對」。

日文是我們不支援的語言。抽出的字串會 fallback 到英文，沒抽出的字串會原樣
顯示中文。**因此判準極簡：畫面上出現任何一個中文字，就是失敗。**

失敗時要指出是**哪一個字串**沒被抽出——記下畫面與該行文字，那就是還留在
程式碼裡的中文字面值。

## L2. 日文系統：藍牙權限彈窗

- **對應**：`System-presented text follows the same rule`
- **前置**：日文系統；**必須刪除 App 重裝**，否則權限已授權過不會再問
- **步驟**：安裝後首次進入任一角色，等系統彈出藍牙權限請求
- **預期**：說明文字為英文（`SideBell uses Bluetooth to connect…`）
- **失敗徵兆**：彈窗出現中文 → `InfoPlist.strings` 沒生效或 `Info.plist` 仍是中文
- **實際**：✅ 通過。彈窗內由 App 提供的說明為英文，外圍標題與按鈕為日文（系統文字，正確）

## L5. VoiceOver 的朗讀語言

- **對應**：`Spoken output matches the interface language`
- **前置**：**英文系統**的 iPad，開啟 VoiceOver（`設定` > `輔助使用` > `旁白`）
- **步驟**：進入患者端，逐一聚焦四個格子與連線指示
- **預期**：
  - 以**英文語音**朗讀，不是中文或其他 CJK 語音
  - 格子有狀態時唸出「標題, 狀態」
- **失敗徵兆**：英文內容被 CJK 語音唸出 → `.lproj` 目錄沒有向系統宣告支援的語言
- **實際**：✅ 通過。朗讀為 `Water, Button, Tap to send a call`，英文語音

## L6. 預設格子的種子語言

- **對應**：`Grid item titles are the caregiver's data, not interface text`
- **前置**：**英文（或日文）系統**，且**刪除 App 重裝**
- **步驟**：
  1. 重裝後進入患者端，看四個預設格子
  2. 把系統語言切換為**繁體中文**
  3. 重新進入患者端，再看那四個格子
- **預期**：
  - 步驟 1：`Water` / `Turn over` / `Bathroom` / `Discomfort`
  - 步驟 3：**維持英文不變**
- **為什麼不變才是對的**：標題一旦種下就是照顧者的資料，不是介面文字。
  他把「喝水」改成「喝溫水」之後，沒有人會期望切換語言時它變回英文。
  雙語家庭切換語言後格子仍是舊語言，那正是格子編輯功能存在的意義。
- **實際**：✅ 通過。日文系統下重裝種下英文標題；切換為繁體中文後四格**維持英文不變**
